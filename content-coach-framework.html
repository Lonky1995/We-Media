这是一份自媒体 Agent 操作手册：它帮你收集素材、研究选题、拆竞品、打磨脚本，并在发布后把反馈写回判断。当前阶段不追求全自动，先保证每一步都能被你掌控。

现在的重点是轻量协作。你人工看平台、投喂链接和观察；Agent 负责来源索引、角度归纳、脚本结构和风险检查。自动化只处理已经稳定重复的动作。
NORTH STAR

用真实 AI 项目和长期协作实验，吸引 AI 创业者、产品实践者和同行交流，而不是做泛 AI 工具流量号。

MODULE 01

素材雷达

把内部项目、Obsidian 反思、外部链接和临时想法收进同一个可追溯素材池。

状态：已搭 v0.1

输入
  • 本地 Vault 白名单：Knowledge、Daily Notes、aboutme、conversations、Projects
  • 手动投喂的新闻、文章、产品发布、截图和口述
  • 项目变化卡：问题、旧方案、改动、洞见、公开风险
最小输出：素材卡 / 信号卡 原始来源与 source_id 这是什么：素材、外部信号、噪音或待核验 可验证事实、个人判断、未知项 公开边界 下一步：归档 / 补充 / 进入选题
当前规则

Discord 不直接抓，读整理进 Vault 的 conversations 和 aboutme。GitHub 上的 My-vault 只做备份历史，不作为第二采集源。

不做

不扫描整个 Vault，不把项目日志自动变成视频，不把私有材料默认视为可公开。

MODULE 02

选题研究

先强信息，后弱建议。选题不是标题生成，而是判断一个话题有没有讨论场、已有角度和你的切入点。

状态：已搭 v0.1

输入
  • 选题研究包：热度、现有角度、与你的连接、弱建议
  • 人工平台样本：抖音、小红书、视频号，每个平台每个关键词 10–20 条
  • 竞品账号卡和竞品视频样本卡
最小输出：研究包 来源索引，每个判断都带 source_id 整体热度：上升 / 持续 / 一次性 / 未知 现有角度地图：拥挤处与空位 适合你的 2–4 个弱建议 下一轮深入讨论问题
关键词池

每次只选 3–5 个词：核心主题词、目标人群词、项目证据词、协作关系词、反向筛选词。

竞品规则

竞品分析必须同时输出可借鉴和不要学。学习结构，不复制人设、焦虑叙事或标题套路。

MODULE 03

脚本协作

不直接写完整逐字稿。先把选题压成一个表达承诺，再做 Brief、口播大纲和拍摄清单。

状态：已搭 v0.1

输入
  • 已确认的选题卡
  • 可公开或可脱敏的一手证据
  • 竞品结构参考和你的表达顾虑
最小输出：脚本工作台 最多 3 个关键追问 脚本 Brief：给谁看、讲什么、证据是什么 3 个开头假设 口播大纲：冲突、判断、证据、方法、反馈 拍摄/录屏清单与删减清单
三种模式

观点型、案例型、教程型。LonkyClaw 优先案例型，但必须翻译成观众问题，不能停在功能更新。

口吻规则

保留第一人称、真实不确定性和产品判断过程。少用“正确答案是”，多用“我目前的判断是”。

MODULE 04

反馈复盘

暂缓。没有作品之前，不提前设计复杂指标。发布第一条并拿到 48 小时反馈后再展开。

状态：发布后启动

启动条件
  • 至少发布 1 条内容
  • 拿到 48 小时后的平台数据
  • 有评论、私信、同行反馈或你的表达感受
占位输出 三个平台发布链接 基础数据：播放、互动、关注、私信 高质量反馈原话 你的表达感受 下一条只验证什么
现在不做

不预设指标权重，不把播放量等同于定位成功，不在没有样本时设计复杂复盘表。

未来作用

让真实反馈回流到选题库、竞品库和风格库，而不是只看单条数据高低。

MODULE 05

日常工作台

把前面模块串成你真的会用的入口：手动触发 + 每周固定回顾，不设置每日强制任务。

状态：已搭 v0.1

输入
  • 你随时丢进来的想法、链接、竞品、项目变化或口述
  • 每周一上午的自动回顾
  • 当前正在推进的唯一动作
最小输出：工作台卡 本周输入队列 本周项目变化卡 本周选题研究包 竞品与风格更新 本周唯一推进 暂缓原因
路由优先级

安全边界 > 来源追溯 > 选题清晰度 > 证据动作 > 表达风格 > 自动化效率。

自动化顺序

先文件归档和 ID，再周度扫描、竞品格式化、发布数据录入；平台样本采集排最后。

先用人工工作流验证，再把稳定、重复、低风险的部分自动化。

三个月后，
看资产，不只看粉丝。

这个系统要帮你判断自己能不能持续表达、能不能吸引对的人，以及是否正在形成自己的角度和风格。

持续表达

你是否能持续讲出自己愿意公开承担的判断，而不是每条都靠热点。

对的人出现

是否有人把问题说成“这也是我的问题”，尤其是 AI 同行、创业者和潜在合作者。

真实素材变多

内容线索是否越来越多来自你的项目、反思和实践，而不是外部热点。

风格更清楚

你是否知道哪些角度、语气、证据动作适合你，哪些虽然有效但不该学。

Next Move

框架完成后，第一步不是写稿。

  1. 选一个主题做真实研究包：来源、热度、现有角度、与你的连接。
  2. 补 3–5 个关键词下的人工平台样本或竞品视频样本。
  3. 确认一个选题后，再进入脚本 Brief，不直接写逐字稿。
