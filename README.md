# We-Media

一个与创作者长期协作的自媒体 Agent 框架。它不替人批量生产内容，而是围绕素材收集、选题、脚本、制作、发布后数据与复盘，逐步沉淀目标、素材、偏好与反馈。

## 当前内容

- `content-coach-research.md`：内容陪跑方法论、平台研究与协作契约。
- `self-media-agent-operating-guide.md`：Agent 的共同记忆、协作模式和最小闭环。
- `self-media-agent-templates.md`：素材、选题、脚本、发布与复盘模板。
- `self-media-agent-implementation.md`：模块化实现蓝图与数据边界。
- `content-coach-framework.html`：可视化框架说明。

## 原则

- 人保留选题、观点、公开边界、发布与策略调整的最终决定权。
- 私人笔记、项目材料和对话默认私有；进入内容前必须确认可公开与脱敏边界。
- 先验证稳定的协作闭环，再自动化高频、低风险步骤。
